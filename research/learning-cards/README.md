# Learning cards

No candidate advances to implementation without a card that answers the five
gates: why it is better, exact pipeline target, technical mechanism, smallest
isolated test, and commercial right. Use the template below and preserve
unknowns instead of filling them with estimates.

## Template

```text
TECHNOLOGY / PROBLEM / WHY IT EXISTS / HOW IT WORKS / CORE ALGORITHM
INPUT / OUTPUT / TEMPORAL INFORMATION / MASK REQUIREMENTS / REFERENCES
MOTION / OCCLUSION / TEXTURE / SHADOW-GLOW / COMPOSITION
TRAINING / INFERENCE / GPU / VRAM / SPEED / QUALITY / FAILURES
CODE-MODEL-WEIGHTS-DEPENDENCY LICENSES / COMMERCIAL POSSIBILITY
CLEANER CURRENT BEHAVIOUR / DIFFERENCE / EXPECTED BENEFIT-COST
MINIMUM EXPERIMENT / SUCCESS CRITERIA
```
