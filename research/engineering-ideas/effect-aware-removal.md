# Effect-aware removal

**Source:** [Project Cloak](https://research.adobe.com/news/cloak-remove-unwanted-objects-in-video/)
motivates recovery of true background; subtitle/shadow effect handling remains
a Cleaner hypothesis until annotated evidence exists.

**Idea:** preserve separate primary overlay and associated-effect masks through
reference selection, inpainting and composition.

**Experiment:** create primary/shadow/glow annotations, test primary-only versus
independent effect masks, and measure residual, background loss and flicker.

**License:** conceptual research only; no external implementation is copied.
