Start with `docs/design-research/DESIGN_SYSTEM_AUDIT.md` and `src/styles.css`. Prefer existing semantic tokens and distinguish UI tokens from intentional media/content values. Do not mass-replace colours or create tokens without a repeated semantic need. Define component states, overflow, themes, motion and accessibility before extending primitives.
