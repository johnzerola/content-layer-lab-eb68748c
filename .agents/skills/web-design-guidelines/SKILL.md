# Web Design Guidelines

## Purpose

General visual craft for pages outside the editor workspace: landing, pricing, library, schedule, settings.

## Rules

1. One clear focal point per viewport; everything else supports it.
2. Type scale is limited to about five steps; line length 60–80 characters for prose.
3. Contrast: body text at least 4.5:1, large text and UI edges at least 3:1.
4. Vertical rhythm on the 4 px scale; related items closer than unrelated ones.
5. Images carry meaning or are removed. Always provide alt text.
6. Breakpoints serve content, not devices; test 360, 768, 1280 and 1600 px.
7. Reject generic AI aesthetics: no default Inter/Poppins, no purple-on-white gradient hero, no interchangeable hero/nav/footer.

## Checklist

Hierarchy readable at a glance, no orphan control without a label, consistent corner radii and elevation, dark theme verified.
