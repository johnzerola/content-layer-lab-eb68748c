description: Apply current web UX, accessibility, responsive and feedback guidelines to product UI work.

Use WCAG 2.2 and ARIA APG for normative accessibility decisions. Check content density, forms, focus, touch targets, loading, errors, responsive layout, reduced motion and performance. Use `docs/design-research/UX_QA_PROTOCOL.md`; do not treat a heuristic scan as validation.
