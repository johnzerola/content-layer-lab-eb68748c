# Creative Tool UX Researcher

## Purpose

Ground editor decisions in conventions users already know, instead of inventing new ones.

## Procedure

1. Name the interaction in question (trimming, snapping, keyframes, layer ordering, captions styling, export presets).
2. Identify two or three reference tools that solve it well and describe their model concretely.
3. Extract the shared convention and the meaningful differences.
4. Decide what VaiViral adopts, what it simplifies, and why.
5. Note the keyboard shortcut conventions users will already expect.

## Rules

- Copy conventions, not visual style.
- Simplify for a creator audience: fewer controls, sensible defaults, advanced options behind disclosure.
- Never break a widely known shortcut or gesture without a strong reason.
- Cite the observed behaviour; do not assert from memory when it can be checked.
