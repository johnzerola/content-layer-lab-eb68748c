# UX audit

The existing editor research audit identifies P0 save/recovery truthfulness and project-time consistency; P1 timeline geometry, cross-surface undo and workspace responsiveness. See `editor-research/EDITOR_UX_AUDIT.md`.

This design audit adds: controls use a mixture of labels and icon-only buttons, so keyboard/focus and accessible-name coverage must be measured across actual routes. Tool-heavy editor panels require standardized beginner tasks before visual redesign. No click count, completion time, abandonment or dead-end metric has been measured yet.
