# Skills map

| Skill | Role | Default mode |
|---|---|---|
| product-design-director | Orchestrates evidence and gates | Read-only planning |
| design-context-intake | Captures route, goals, tokens and constraints | Read-only |
| editor-ux-designer | Creative-editor UX | Task audit |
| ux-flow-engineer | Journey and friction measurement | Isolated browser |
| interaction-designer | States, feedback and input models | Small-diff validation |
| design-system-engineer | Semantic token and component governance | Read-only then reviewed diff |
| frontend-design | Visual implementation quality | Small reviewed diff |
| web-design-guidelines | Responsive/accessibility guidelines | Review |
| visual-qa-gate | Screenshot and visual regression | Isolated browser |
| accessibility-gate | WCAG/APG and manual checks | Isolated browser |
| frontend-performance-gate | Trace-based performance checks | Isolated browser |
| creative-tool-ux-researcher | Public pattern research | Read-only research |
| ux-self-learning | Promotes verified learnings only | Evidence-gated |

These are complementary to existing `vaiviral-product-design`, `impeccable` and editor-engineering skills. The latter retain their scoped responsibilities; this map does not merge their memories or authorize product changes.
