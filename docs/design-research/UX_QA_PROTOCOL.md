# UX QA protocol

Use an isolated browser profile and local fixtures. For a task, capture before/after screenshots, viewport, browser, route, fixture revision, clicks, elapsed time, repeated clicks, errors, opened panels, backtracking, undo/recovery and final state. Test keyboard, 200% zoom, a narrow viewport and reduced motion where relevant. Compare screenshots only when route, viewport, fixture and fonts are controlled.

Default order: discover, audit, define problem, study references, hypothesis, small diff, component state, user journey, accessibility, performance, visual diff, metrics, approve/reject. No browser command may use a personal profile or private production media by default.
