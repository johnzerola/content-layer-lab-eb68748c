# Editor V2 — atalhos de teclado

| Atalho | Ação |
|---|---|
| `Espaço` | Reproduzir ou pausar |
| `Delete` / `Backspace` | Remover seleção |
| `Ctrl/Cmd + Z` | Desfazer |
| `Ctrl/Cmd + Shift + Z` | Refazer |
| `Ctrl/Cmd + D` | Duplicar os clipes selecionados |
| `S` | Dividir clipe selecionado na agulha |
| `←` / `→` | Avançar ou voltar um frame |
| `Shift + ←` / `Shift + →` | Avançar ou voltar um segundo |
| `Shift + Enter` em um item | Adicionar ou remover da seleção múltipla |
| `Esc` | Limpar seleção |
| `←` / `→` com item focado no canvas | Mover horizontalmente 1% |
| `↑` / `↓` com item focado no canvas | Mover verticalmente 1% |
| `Shift` + seta com item focado | Mover 5% |
| `←` / `→` na alça de rotação | Girar 1°; com `Shift`, 15° |

Os atalhos globais não são executados enquanto o foco está em `input`, `textarea`, `select` ou conteúdo editável. Todos os controles principais mantêm foco visível.
