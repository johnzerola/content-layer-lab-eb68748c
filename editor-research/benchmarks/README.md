# Editor UX and performance benchmarks

Record each task with the same fixture, viewport, browser version, input method and cache state. Measure clicks, elapsed time, errors, opened panels, mouse distance, undo success and preview feedback. Do not score external products without equal tasks and permission.

Performance runs also record first-frame time, seek and scrub latency, dropped frames, timeline and canvas FPS, memory, CPU and GPU when observable. Warm and cold cache are separate results. No task is executed by this document.
