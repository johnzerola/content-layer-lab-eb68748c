# Editor Development MCP tools

`editor-development-mcp` is separate from `cleaner-research-mcp` and is read-only or research-record oriented. It inspects editor/state/timeline/canvas/player/render/media/audio surfaces; supplies UX/performance protocols; searches curated research; records failures; and designs experiments. Its task/audit tools do not claim a browser session, measured performance or completed editing action.

Run it with `research/.venv/Scripts/python.exe editor-research/server.py`.
