# Open-source research

OpenCut publicly describes a rewrite toward an Editor API, plugins, Rust core, headless mode and MCP; its currently running product is described as Classic. Treat that as an architectural reference, never as proof of our implementation. [OpenCut](https://github.com/opencut-app/OpenCut).

Mediabunny is a browser media toolkit focused on selective reading, streaming, demux/mux and WebCodecs paths. Test it per operation; it is not a blanket replacement for backend FFmpeg. [Mediabunny](https://mediabunny.dev/).

WaveSurfer is a waveform/playback candidate. Precomputed peaks are relevant for large files, while VBR timing requires validation. [WaveSurfer docs](https://wavesurfer.xyz/docs/). Remotion is a reference for React composition and server rendering; it is not installed or selected. [Remotion licensing](https://www.remotion.dev/docs/licensing).
